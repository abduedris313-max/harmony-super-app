# Harmony OS AI Tool Mini App Starter

A specialized starter template designed for building AI-powered utility mini apps (chat assistants, prompt refiners, document summarizers) for the **Harmony OS Super App**.

## Features
- **Prompt Mode Selector**: Switch between Clarity, Executive Brief, and Technical RFC templates.
- **Simulated Inference & Metrics**: Demonstrates generation state transitions and token formatting.
- **One-Click Clipboard**: Uses `Harmony.clipboard.writeText()` for cross-platform copy actions.
- **Persistent History**: Stores past prompt transformations with `Harmony.storage`.
